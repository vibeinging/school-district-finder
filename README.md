# school-district-finder · 你住的地方，能上哪个小学

北京朝阳区小区 → 对口小学查询工具（网页版）。

## 当前状态（2026-11-03）

- ✅ 朝阳区数据全量完成：7,651 个住宅小区 / 241 所小学（2026 年版）
- ✅ 网页版上线：搜索 / 学校反查 / 政策矩阵，mobile-first，深色模式
- ✅ 各区摸底完成：北京 16 区中仅朝阳区有小区名公开查询系统；东城/丰台/通州为
  实名制系统；其余各区需每年招生季从官方公告的各校招生简章整理划片表
  （详见 `docs/research/2026-11-03-chaoyang-enrollment-policy-matrix.md`）

## 目录结构

```
school-district-finder/
├── scripts/                  # 数据加工（git 仓库内）
│   ├── build_dataset.py      # 本地数据 → SQLite（全参数绑定）
│   └── export_web.py         # SQLite → web/data.js（含拼音/首字母索引）
├── web/                      # 网页版（纯静态，零依赖，可双击打开）
│   ├── index.html / app.css / app.js
│   └── data.js               # 由 export_web.py 生成（约 2.2MB）
├── docs/
│   ├── research/             # 政策矩阵
│   └── reports/              # 项目 review 报告
├── crawler/                  # ⚠️ 数据获取与接口笔记（仅本机运行，不入 git 仓库）
├── data/                     # ⚠️ 原始记录 + SQLite（本机留存，不入 git 仓库）
└── logs/
```

**仓库边界约定**：git 仓库只包含应用（web/）、数据加工脚本（scripts/）与文档；
数据获取相关代码与笔记（crawler/，含 notes/）以及原始数据（data/）仅保存在
本机，已在 .gitignore 排除。

## 使用

```bash
# 网页版：任选其一
open web/index.html                    # 直接双击/打开即可用（file:// 支持）
cd web && python3 -m http.server 8765  # 或起本地服务： http://127.0.0.1:8765

# 数据更新流程（每年招生季；数据获取在本机 crawler/ 目录进行，约定见其 notes/）
python3 scripts/build_dataset.py           # 构建 SQLite
.venv/bin/python scripts/export_web.py    # 导出 web/data.js（改版记得更新 ?v= 版本号）
```

网页版功能：小区搜索（中文/拼音/首字母）→ 两档结果（2017-06-30 前购房单校划片 ·
后购房多校派位）；学校反向查询对口小区；政策矩阵页；热门区域快捷入口、搜索历史；
深色模式自适应。

## 数据口径（重要）

- 数据源为**朝阳区招生考试中心**公开发布的入学服务片信息（2026 年版，小学），
  仅供具有住宅性质的居住地参考；实际入学办法以当年官方规定为准。
- `school_main`：单校划片直接对应学校（部分小区为多校）。
- `schools_after30`：**2017-06-30 后取得不动产权证家庭**的片区统筹派位范围
  （多校划片）。官方口径见《朝阳区关于2026年义务教育阶段入学工作的实施意见》
  ——该日期后取得产权证的地址不再对应一所学校，参加片区统筹分配。
- 划片数据每年 4~6 月更新，需要按年刷新。
